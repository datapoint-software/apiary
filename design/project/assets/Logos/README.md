# Logos

- `datapoint-logo.svg`: the Datapoint Software wordmark ("datapoint .software"), single ink. As a file it draws in black; inline its SVG where it must follow the theme, so it takes `currentColor` (`ink-2` in the sidebar footer). Required next to the attribution "Based on Apiary by Datapoint - Sistemas de Informação, Lda." in every version of the admin interface. Use it only as TRADEMARKS.md allows.

Apiary itself has no logo yet: see Brand in the README.
